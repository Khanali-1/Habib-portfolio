## Getting Started

Clone the repository:

```bash
git clone https://github.com/Khanali-1/habib-portfolio.git
```

Navigate to the project:

```bash
cd habib-portfolio
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and configure the required environment variables for the contact form.

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Environment Variables

Configure the following variables in `.env.local` for email functionality:

```env
SMTP_HOST=
SMTP_PORT=
SMTP_USER=
SMTP_PASS=
CONTACT_EMAIL=
```

Never commit your actual environment variables or credentials to GitHub.
